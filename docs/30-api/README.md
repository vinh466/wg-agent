# API contract

> **This directory holds GENERATED documentation. Never hand-edit it.**

The source of truth is `api/proto/wgagent/v1/*.proto` — see `REQ-API-001` in
[SPEC-04](../20-spec/SPEC-04-api-conventions.md) and
[ADR-0003](../10-decisions/ADR-0003-protobuf-source-of-truth.md).

## State

Nothing is generated. The implementation is rebuilt from the specification, and the toolchain
that renders the contract into server code and a published description is chosen when the API
layer is implemented from SPEC-04. Output generated by an earlier toolchain was removed rather
than kept, because a generated file whose generator is gone drifts silently the first time the
`.proto` changes.

## What the contract must hold

A check on the contract, whatever toolchain produces it, asserts the properties that cannot be
corrected within `v1`, because a wrong field cardinality is a breaking change:

- `mtu`, `manage_routes` and `enabled` carry explicit presence under `REQ-API-076`, while
  `listen_port` and `fwmark` do not
- identity is outside `spec` and `status` under `REQ-RES-034`
- `handshake_age_seconds` is nullable under `REQ-RES-023`
- the adoption request can express omission under `REQ-RCN-066`
- every REST route of `REQ-API-063` is reachable

`WatchPeerStatus` is deliberately absent from the surface: nothing specified its request scope,
its stream element or what emitted an event, and an RPC frozen in the wrong shape cannot be
changed within `v1`. It arrives with the watch work deferred under `B-05` in the
[backlog](../60-planning/backlog.md).

## Compatibility checking

Blocking a compatibility-breaking change within a package version is `REQ-API-061`, deferred
under `B-05`.

A linter enforcing AIP style flags two things the contract does on purpose. It asks for a
dedicated response message per RPC, while returning the resource itself is what AIP-131
prescribes and what the REST table of `REQ-API-063` implies — `GET /v1/interfaces/{name}`
answers with an `Interface`. Those two rules are excepted when a linter is configured.
